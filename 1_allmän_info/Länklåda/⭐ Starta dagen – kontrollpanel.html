Starta dagen

Den här sidan hjälper dig att starta arbetsdagen med rätt ordning och rätt filer.

1. Öppna VS Code i rätt mapp

Dubbelklicka på skrivbordsikonen som öppnar 1_Mallen direkt.

Om du vill skapa en genväg:

"C:\Program Files\Microsoft VS Code\Code.exe" "C:\Users\11733\iCloudDrive\1_Mallen"

2. Skapa dagens sida

Öppna terminalen i VS Code och kör:

.\create_new_day.ps1

Det skapar dagens HTML‑fil och lämnar gamla filer orörda.

3. Starta Go Live

För att undvika att Go Live startar i fel katalog:

  • Stäng alla HTML‑flikar
  • Stäng VS Code
  • Öppna VS Code via skrivbordsikonen
  • Öppna dagens HTML‑fil
  • Tryck Go Live

4. Uppdatera GitHub

Kör ditt script:

.\Git.ps1

Det committar och pushar automatiskt om det finns ändringar.

5. Börja dagens anteckningar

  • Skriv dagens rubrik
  • Lägg till noteringar och arbetsmoment
  • Spara ofta
