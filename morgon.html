Viktiga kommandon för att behärska GitHub

För att behärska GitHub (och verktyget Git som det bygger på) behöver du ha koll på ett antal grundläggande och även några avancerade kommandon. Jag använder VS Code, för den lokala versionshanteringen på datorn, så redan här möts vi av tvetydighet som inte är något att hänga upp sig på.

GitHub är plattformen i molnet där koden sparas och hanteras eller delas.

Givetvis skulle också programet Git kunna användas användas lokalt, men jag har valt att beskriva VS Code som lokal versionshanterare. Det känns mera naturligt, då det programet används i många andra sammanhang.
