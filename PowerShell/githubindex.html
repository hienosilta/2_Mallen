PowerShell -

Windows PowerShell är en lätthanterad kommandoradsgränssnitts- och skriptmiljö för att automatisera administrativa uppgifter i Windows-baserade system. Windows PowerShell är förinstallerat på alla moderna versioner av Windows-operativsystemet.

GitHub -

AI-genererad översikt

GitHub är en molnbaserad plattform som låter utvecklare lagra, hantera och dela sin källkod.Det fungerar som ett socialt nätverk för programmerare, vilket underlättar lagarbete och versionshantering av alla mjukvaruprojekt. Här är de viktigaste punkterna för att förstå vad det är och hur det fungerar:

1. Motorn: Git (Versionskontroll)

GitHub är baserat på Git , ett versionshanteringssystem skapat av Linus Torvalds. • Den registrerar alla ändringar som görs i ett projekts filer. • Det låter dig "resa tillbaka i tiden" för att återställa tidigare versioner om något går fel. • Det förhindrar att utvecklare överlappar varandras arbete när de ändrar samma fil.

2. Lagring: Arkiv

Ett repository (eller "repo" ) är den virtuella mappen där hela projektet lagras: kod, bilder, dokumentation och ändringshistorik. Det kan vara: • Offentlig: Vem som helst i världen kan se koden, lära sig av den eller föreslå förbättringar (grunden för öppen källkod ). • Privat: Endast personer som är auktoriserade av projektägaren har åtkomst.

3. Viktiga samarbetsverktyg

• Fork: Låter dig kopiera någon annans projekt till ditt eget konto för att experimentera eller göra ändringar utan att ändra originalkoden.

• Pull Request: Om du förbättrar ett projekt skickar du en "Pull Request" till den ursprungliga skaparen för att granska dina ändringar och, om de gillar dem, sammanfoga dem med huvudprojektet.

• Problem (Problem/Uppgifter): Ett avsnitt för att rapportera fel, diskutera förbättringar eller planera kommande arbete.

4. Portfolio för programmerare

Idag fungerar en GitHub-profil som en programmerares CV . Företag granskar kandidaters konton för att bedöma kvaliteten på deras kod, hur de samarbetar med andra och vilka projekt de har arbetat med. Om du funderar på att börja använda det, låt mig veta:

• Vill du veta hur du skapar ditt första konto och arkiv ?

• Vill du förstå den exakta skillnaden mellan Git och GitHub ?

• Vill du lära dig ett specifikt programmeringsspråk ?
