Tillbaka

De absolut viktigaste kommandona, uppdelade efter arbetsflöde.


1. - git init
Startar och konfigurerar (Görs oftast en gång)
Skapar ett helt nytt lokalt Git-arkiv (repository) i den mapp där du står.

1.1. - git clone
Kopierar ett befintligt arkiv från GitHub till din dator.

2. - git status
(Spara ändringar) i dagliga arbetsflödet. Det viktigaste kommandot för överblick. Visar vilka filer som har ändrats, skapats eller tagits bort.

2.1 - git add
Lägger till specifika filer i "staging area" (gör dem redo att sparas). Använd git add . för att lägga till alla ändrade filer.

2.2 - git commit -m
"Ditt meddelande" Sparar dina förberedda ändringar i en "commit" (en sparfil i historiken) med en kort beskrivning av vad du gjort.
